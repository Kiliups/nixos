# Development options

This file is generated from the option metadata in
[`kiliups/nixos`](https://github.com/kiliups/nixos/tree/main/modules/development).
Do not edit it manually.

Set options in your Home Manager configuration:

```nix
{
  development.shell.enable = true;
  development.herdr.config = builtins.readFile ./herdr.toml;
  development.tmux.config = builtins.readFile ./tmux.conf;
  development.lazyvim.config = ./nvim;
  development.agents.packages = [ "opencode-desktop" ];
  development.agents.skills = {
    project = ./skills/project;
  };
  development.languages.go.enable = false;
}
```

## MCP server integration

Enabling any AI agent also enables Home Manager's shared MCP registry.
Define servers once under `programs.mcp.servers`; Claude Code, Codex, and
OpenCode receive them automatically. Zed also receives them when
`development.zed.enable` is enabled. Cursor receives the same servers in
`~/.cursor/mcp.json` and the shared skills through `~/.agents/skills`.

Type: `strings concatenated with "\n"`

Default:

```nix
''
  # Agent Instructions

  - Always make the smallest idiomatic change that cleanly solves the task while remaining DRY, KISS and maintainable.
  - Follow the project's existing style, structure, and conventions.
  - Never add AI attribution to commit messages (no "Co-authored-by", "Generated by", etc.).
  - Before committing, pushing, or opening a PR, show the proposed changes and commit message and always wait for approval.
  - When writing German, use normal umlauts instead of replacements such as `oe`.
  - Avoid unnecessary complexity, over-engineering, and premature optimization.
  - Remove code made obsolete by your changes.
  - If a task requires an unavailable package, use `nix shell` to run it.
''
```

## `programs.mcp.servers`

MCP server configurations written to `$XDG_CONFIG_HOME/mcp/mcp.json`.

Each server is either a local (stdio) server via `command`
or a remote (HTTP/SSE) server via `url`.

Besides declared options, arbitrary MCP fields are allowed.


Type: `attribute set of (open submodule of (JSON value))`

Default:

```nix
{ }
```

Example:

```nix
{
  everything = {
    command = "npx";
    args = [ "-y" "@modelcontextprotocol/server-everything" ];
  };
  context7 = {
    url = "https://mcp.context7.com/mcp";
    headers.CONTEXT7_API_KEY = "{env:CONTEXT7_API_KEY}";
  };
  codeberg = {
    command = "/path/to/forgejo-mcp";
    args = [ "transport" "stdio" "--url" "https://codeberg.org" ];
    env.FORGEJO_ACCESS_TOKEN.file = "/run/secrets/codeberg_token";
  };
}

```
